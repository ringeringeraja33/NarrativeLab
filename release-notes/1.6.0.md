# WritingLab 1.6.0

## 中文

- 插件对外名称更新为 WritingLab，并保留原有 `narrative-lab` 插件 ID，现有安装可以直接升级。
- 新增按项目配置的功能模块与项目预设，支持纯写作、随笔、科研论文、文献综述、小说、完整叙事和自定义工作流。
- 项目创建后可以随时启用或停用模块；停用不会删除数据，也不会继续加载相应视图、索引、观察器和后台服务。
- 未启用场景的轻量项目使用项目专属的 Obsidian 原生 Base 管理文稿，文件名为 `writing-项目名.base`。
- 未启用资料库或叙事模块时，不再生成无关文件夹和 `System` 元数据。
- 修复项目启动白屏、切换项目时短暂显示旧画布、启动加载缓慢以及写作速度出现负数的问题。
- 字数统计和写作记录可以作为独立的轻量功能使用。

## English

- Rename the user-facing plugin to WritingLab while retaining the existing `narrative-lab` plugin ID for seamless upgrades.
- Add per-project modules and presets for plain writing, essays, research papers, literature reviews, novels, full narrative projects, and custom workflows.
- Allow modules to be enabled or disabled after project creation. Disabled modules keep their data and stop loading their views, indexes, observers, and background services.
- Open lightweight projects without Scenes through a project-specific native Obsidian Base named `writing-<project>.base`.
- Avoid creating unrelated folders and `System` metadata when Library or narrative modules are disabled.
- Fix blank project tabs, stale Canvas content during project switches, slow startup loading, and negative writing-speed values.
- Keep word counting and writing tracking available as independent lightweight features.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
