# NarrativeLab 1.3.5

Spreadsheet data-safety hardening, Story Graph filtering improvements, and a more usable Library Base.

## Improvements

- Library Base now mirrors horizontal scrolling at the bottom of the window, keeping wide tables usable without scrolling to the final row.
- Story Graph starts with no legend selected and displays no nodes until a label is chosen.
- Story Graph capacity increases from 120 to 300 nodes and reports when less-connected nodes are omitted.
- The embedded spreadsheet runtime now registers only the Univer presets NarrativeLab uses, reducing bundled code and unused dependencies.

## Spreadsheet data safety

- XLSX and NarrativeLab metadata writes use atomic promotion plus a recovery journal, preventing interrupted saves from leaving mismatched files.
- Reset, import, automatic repair, corrupt-file recovery, and worksheet deletion preserve timestamped backups before replacing data.
- Sparse Univer snapshots never clear omitted cells or worksheets. Clear commands affect only their explicit ranges, while worksheet deletion requires an explicit delete mutation.
- Long cell content and row, column, corner, and worksheet titles survive Excel's cell and sheet-name limits through the sidecar metadata.
- External Excel edits no longer resurrect stale formulas, cleared wikilinks, removed links, or older cached workbook data.
- Unreadable canonical workbooks can recover from retained legacy copies; automatic cleanup no longer removes potential workbook, CSV, or index recovery files.
- Empty imports and empty or incomplete snapshots cannot overwrite an existing workbook.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts remain `main.js`, `manifest.json`, and `styles.css`.
