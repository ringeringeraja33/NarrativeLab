# NarrativeLab 1.4.4

Makes project internals quieter in Obsidian, improves Library creation and character data migration, and closes several persistence and cleanup gaps.

## Cleaner project navigation

- The Files view now hides project `Library`, `System`, and `Canvas` folders, `series.json`, and unsupported file types without changing or deleting vault contents.
- A ribbon eye button reveals or hides all managed internal items at any time and remembers the choice.
- Newly mounted file rows are filtered before the next paint, preventing the first-open flash when folders expand.
- Navigator rows use compact indentation without empty sequence gutters and retain the Notes, Scenes, Research order.

## Safer series and Library workflows

- Missing projects can be removed from a series as metadata-only stale entries; no file or folder is moved or deleted.
- Series project resolution recognizes both the display title and actual project folder name.
- The native Library Base New button uses the same category-aware creation flow as Profiles, creating new entities directly in their correct folder.

## Character fields and profile editing

- Character defaults now provide separate Family and Early Life fields.
- Existing legacy family/background content migrates into Early Life without overwriting already populated data.
- Every resizable profile text field records its final dragged height reliably, including immediately before a rerender, collapse, tab close, or reopen.

## Interface cleanup

- Removed the persistent explanatory paragraph above populated plotline lists while keeping the empty-state onboarding guidance.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.4.zip`.
