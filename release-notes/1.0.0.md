# NarrativeLab 1.0.0

This is the first release prepared for the Obsidian Community directory.

## Highlights

- A unified project workspace for scenes, manuscript writing, structure, research, statistics, Library assets, spreadsheets, and Narrative Canvas.
- Recursive `Library/` categories synchronized with native Obsidian Base views.
- Project-safe multi-tab behavior: several projects can remain open without sharing selection or category state.
- English and Simplified Chinese interfaces.
- Horizontal and vertical archive-page layouts saved per category and project.
- Univer Concept Grid stored as a normal `.xlsx` file, including formatting, formulas, Markdown, HTML, and Obsidian wikilinks.
- Narrative structure templates, project presets, scene templates, and beat placeholder generation.
- Series-aware shared and local assets with transaction journals and rollback.
- Native Canvas projections, project bundles, and manuscript exports.

## Community packaging

The complete spreadsheet runtime is included in `main.js`. A standard Obsidian installation needs only the three attached assets:

- `main.js`
- `manifest.json`
- `styles.css`

No account, payment, advertising, telemetry, or remote-code download is used.

## Compatibility

Requires Obsidian 1.12.7 or later. Desktop and mobile are supported; Scrivener import and native folder selection remain desktop-only.

Back up important vaults before the first production rollout, particularly before category deletion, series migration, or project import.
