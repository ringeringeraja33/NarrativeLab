# NarrativeLab 1.3.9

Added practical word-count correction controls and corrected the yearly heatmap direction.

## Writing tracker corrections

- Tracker settings can apply a signed word-count adjustment to a selected project and date.
- Unattributed statistics can be assigned to a selected project or permanently deleted.
- Every correction dialog states that it changes statistical records only; NarrativeLab does not create, restore, edit, or delete manuscript files through these controls.
- The sidebar no longer describes statistical history as recoverable manuscript content.

## Data safety

- Project corrections are written before the live vault ledger is changed, with serialized mutations, staged files, backups, and failure recovery.
- Corrections stop if any project statistics file is unreadable, preventing partial project scans from replacing the vault total.
- Interrupted global-ledger writes resume from the fully staged temporary payload.

## Heatmap

- The yearly heatmap now reads from January on the left to December on the right.
- Month labels remain correct when a displayed week crosses a month or year boundary.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.3.9.zip`.
