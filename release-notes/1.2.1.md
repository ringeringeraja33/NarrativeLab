# NarrativeLab 1.2.1

A data-safety and series-workflow follow-up to 1.2.0.

## Fixes

- Moving or deleting a project folder no longer recreates empty `Library` / `System` / `Scenes` trees at the vacated path. Writes and folder creates consult a project-root tombstone first.
- Custom Library category folders survive a local project move. Automatic reconcile adopts unknown folders instead of trashing ones that still have notes.
- Adding a book to a series no longer treats `Library/datasheet.xlsx` or `library.base` as shared merge conflicts. Those files stay with the book.
- Creating a project at `/` (default / vault root) no longer places it inside another project or series folder. A slash in the location field means the vault root, not “list every folder.”
- Series convert and dissolve ignore Finder leftovers such as `.DS_Store`.
- Unreadable `board.json`, `field-templates.json`, and `plotgrid.json` are kept instead of being overwritten by an empty autosave or a legacy migration.
- Writing sprints refuse to start when the project word count is still zero, so an unfinished index cannot record the whole book as one sprint.
- Concept Grid right-click submenus close the previous flyout immediately instead of stacking after a hover delay.
- Navigator indents series → project → Notes / Scenes / Research correctly.

## Additions

- The “Add project to this series” dialog can create a new project in the series, using the shared series Library.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
