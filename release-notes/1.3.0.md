# NarrativeLab 1.3.0

A Concept Grid save, isolation, and data-loss follow-up to 1.2.5.

## Fixes

- Autosave always writes the bound project's `Library/datasheet.xlsx`. Focusing another book no longer cancels a pending save or writes into the wrong folder.
- Each open project keeps its own in-memory datasheet cache, so an incomplete snapshot from one book cannot skip the overwrite guard on another.
- Disposing a spreadsheet no longer treats a sparse Univer teardown snapshot as cell deletes, and that pull is not published back into the view for a second save.
- After Delete / Clear, a stale `getValue()` cannot restore first-row, first-column, A1, or body text the mutation stream already cleared.
- Empty Excel cells are not filled back from a stale `datasheet.nlmeta.json`. Markdown and wikilinks restore only when the live display still matches.
- Univer commands and `workbook.save()` snapshots are ignored unless they belong to this grid's workbook id. A datasheet change in the vault refreshes only that project's open grid.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
