# NarrativeLab 1.2.0

A project-isolation and writing-tracker follow-up to 1.0.1.

## Fixes

- Switching projects now isolates session state that used to leak between books: link-scanner lookups, Concept Grid mention cache, undo, setup/payoff stems, story-graph filters, navigator search/selection, manuscript cursor restore, floating sticky notes, and scene inspector / notes / synopsis sidebars.
- Writing-tracker session baselines no longer carry one book's word total into another. Importing a project ledger replaces history instead of merging it.
- Bound project tabs skip refresh when another book is focused, so a background Timeline, Manuscript, Library, or Research leaf cannot be painted from the live index of a different project.
- Word counts ignore `%%comments%%`, HTML comments, fenced code, HTML tags, and Markdown syntax, while still counting readable prose.

## Additions

- Writing tracker: fixed-size heatmap cells, a full-width daily total bar, range charts that no longer rebuild the whole page, and goal rings labeled Today's / Weekly / Monthly goal.
- Settings: writing-goal options live under Tracker; YAML, wikilink, and count options live under Scenes.
- Concept Grid: plotline subway labels are right-clickable, Univer menus keep a hover assist, and Connected notes open as a real hover submenu.
- Desktop floating sticky notes are stamped with the active project and hidden when you switch to another book. Legacy notes without a project stamp stay vault-wide.
- Attribution for [obsidian-webnovel-assistant](https://github.com/HatanoChihiro/obsidian-webnovel-assistant) in the README and NOTICE.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
