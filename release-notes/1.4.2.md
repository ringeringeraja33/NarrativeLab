# NarrativeLab 1.4.2

Keeps Obsidian's Files view focused on content the user can actually open while preserving all NarrativeLab project data on disk.

## Cleaner Obsidian file tree

- Every project `System` folder is hidden from Obsidian's Files view, including all of its internal data files.
- `series.json` (shown as `series` when extensions are hidden) is hidden wherever it appears.
- Other file types are hidden only when Obsidian has no registered view capable of opening them. Formats supported by Obsidian or another installed plugin remain visible.
- The rules update automatically when folders expand or the workspace layout changes.
- A new NarrativeLab setting can restore all of these items to the Files view at any time.

This is display-only cleanup: no files are deleted, moved, renamed, excluded from search, or made unavailable to NarrativeLab.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.2.zip`.
