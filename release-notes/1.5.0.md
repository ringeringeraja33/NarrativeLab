# NarrativeLab 1.5.0

Improves Library profile layout, Base column persistence, and related-note workflows.

## Library profile layout

- Large profile sections can be collapsed and reordered in both horizontal and vertical layouts.
- Horizontal sections collapse into compact header rows; vertical sections fold into narrow side tabs so collapsed content no longer consumes a full column.
- Section order and collapse state persist per Library category across rerenders, tab switches, and project reloads.
- Drag handles and interaction guards keep section reordering separate from field editing and scrolling.

## Native Library Base

- Column visibility synchronization waits for the rendered Base state to stabilize before persisting it.
- Transient Obsidian frames are ignored, preventing fields from briefly disappearing, returning, or overwriting the user's most recent visibility choice.
- Existing column order, width, sorting, and ordinary table interactions remain independent from field visibility persistence.

## Related notes and interface polish

- Each related-note row has a direct open action alongside its relationship controls.
- The partial-sync marker has an explicit explanation while keeping the complete stored relationship intact.
- Custom and built-in profile sections use more consistent controls and stable rendering in long, scrollable layouts.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.5.0.zip`.
