# NarrativeLab 1.5.7

## 中文

- 文件浏览器的隐藏规则现在只作用于 NarrativeLab 已登记项目和有效系列的实际内部路径。用户在库根目录或其他位置自行创建的同名 `Library`、`System`、`Canvas` 文件夹不会再被误隐藏。
- `series.json` 也只会在属于有效 NarrativeLab 系列时隐藏，普通同名文件继续遵循 Obsidian 自身的文件类型处理。
- 移除了按文件夹名称全局隐藏的 CSS 规则，避免文件树加载时先错误隐藏用户目录。
- 更新 `tslib` 至 2.8.1、`highlight.js` 至 11.12.0，并通过完整测试、启动测试和发布资源一致性检查。

## English

- Scope Files-view hiding to the exact internal paths of registered NarrativeLab projects and validated series. User-created folders named `Library`, `System`, or `Canvas` elsewhere in the vault remain visible.
- Hide `series.json` only when it belongs to a validated NarrativeLab series; unrelated files follow Obsidian's normal file-type handling.
- Remove global name-only CSS hiding rules so user folders are not briefly or permanently hidden while the file tree loads.
- Update `tslib` to 2.8.1 and `highlight.js` to 11.12.0, with full unit, startup, and release-asset validation.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
