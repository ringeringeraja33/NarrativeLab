# NarrativeLab 1.3.1

Project-scoped default artifact naming for datasheet, Library Base, and corkboard Canvas.

## Fixes

- New default filenames now include project names:
  - `Library/datasheet-<project>.xlsx`
  - `Library/library-<project>.base`
  - `Canvas/corkboard-<project>.canvas`
- Existing legacy files are migrated on load so older projects keep working.
- Renaming a project now renames these per-project artifact filenames as well.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts remain `main.js`, `manifest.json`, and `styles.css`.
