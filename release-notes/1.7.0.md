# WritingLab 1.7.0

## 中文

- 科研论文 / 文献综述项目默认打开资料库，分类为文献、论点、论据、事实；不再带角色、地点和小说人物关系。
- 无场景项目的文稿页留在 WritingLab 内，可新建文稿；不再一打开就换成空白的 Obsidian Base 表格。新项目会生成一份草稿。
- 论文项目的「整理」包含平铺画布、列式白板和表格；节点式演示画布不再作为科研预设的一部分。
- 资料图谱在学术项目中使用引用 / 支持 / 反驳，并隐藏场景节点与家庭、恋爱等人物关系。
- 字数口径分为通用、学术、叙事和自定义。学术口径会去掉脚注正文、常见引用标记和文末参考文献。
- 可按文件夹记录写作量；项目页签按文稿 / 整理 / 规划 / 资料库 / 演示分组，模块可单独开关。
- 修正模块开关说明与开关重叠、文稿工具栏按钮挤在页签上等问题。

## English

- Research-paper and literature-review projects open Library first, with literature, claims, arguments, and facts. Character, location, and fiction relationship types stay off.
- Scene-less manuscripts remain in WritingLab with document creation instead of replacing the tab with an empty Obsidian Base. New projects seed a starter draft.
- Organize for paper projects includes tiled canvas, column board, and table. The node-based presentation canvas is not part of the research presets.
- Academic Story Graphs use cites / supports / refutes and hide scene nodes and character-relation legends.
- Word-count profiles: general, academic, narrative, and custom. Academic counting omits footnote bodies, common citation markers, and trailing bibliographies.
- Folder writing trackers and grouped project tabs (Manuscript, Organize, Planning, Library, Presentation) are available independently of narrative scenes.
- Fix overlapping module-picker copy and crowded manuscript toolbar actions.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
