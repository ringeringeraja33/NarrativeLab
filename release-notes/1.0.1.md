# NarrativeLab 1.0.1

A follow-up to the 1.0.0 community packaging release.

## Fixes

- Unlinking a note from a Concept Grid cell keeps the visible name as ordinary text. The chip × and the context-menu Unlink action no longer empty the cell.
- Library Archive/Browse mode and the last category tab are remembered per project. Opening a second project no longer inherits the previous book's Library chrome.
- Plotlines no longer leak across projects when you switch books.
- Univer **Clear contents** and **Clear all** now update NarrativeLab's Markdown source. Reopening the cell editor after those commands shows an empty cell instead of the old text.
- Connected-notes chips no longer pick up Obsidian's default button inset, and the Chinese convert action is labeled 「转为研究」.

## Additions

- Writing tracker: a right-sidebar panel (vault / project), a vertical net-word heatmap, a ribbon-opened Tracker page, and a Tracker settings tab.
- Desktop floating sticky notes with colour, pin, Markdown preview, and save-to-folder.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
