# NarrativeLab 1.4.5

Improves Library data integrity, multi-canvas and spreadsheet workflows, project navigation, and writing-statistics isolation.

## Library profiles and relationships

- Profile saves preserve readable built-in and custom fields when an editor provides a partial snapshot.
- Frontmatter field ordering stays consistent across profile edits, native Base changes, migrations, and reloads.
- Character, Location, and Codex relationships can be edited from profile pages and mirrored into the Story Graph.
- Relationship references follow renames and retain existing Markdown prose.
- Native Library Base views provide a synchronized horizontal scrollbar at the bottom of the pane.

## Narrative Canvas and Concept Grid

- Each project can keep multiple Narrative Canvas documents in a project-scoped card box.
- Canvas selection, rename, deletion, opening, and tab state stay attached to the owning project.
- Concept Grid retains more workbook styling when rebuilding sheets from Univer state.
- Spreadsheet persistence continues to reject incomplete or destructive snapshots.

## Navigation and settings

- Series rows can be collapsed even when they contain the active project.
- Search and filtering temporarily reveal matching series without overwriting the user's manual collapse state.
- Timeline drag-scroll settings now use the same framed disclosure component as other collapsible settings sections.

## Writing statistics

- Project switching suspends tracker mutations until the new project's ledger and scene index are ready.
- Delayed file events are discarded when they no longer belong to the active project.
- Restarting a writing session resets its flush cursor, preventing a previous project's baseline from appearing as a large deletion.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.5.zip`.
