# NarrativeLab 1.4.3

Makes Library profiles more configurable and closes the remaining spreadsheet row-height persistence gaps.

## Configurable profile layouts

- Reorder profile sections and individual fields in Character, Location, and Codex profiles, in either horizontal or vertical layout.
- The selected visible-field order is mirrored into Markdown YAML frontmatter and the native Library Base view.
- Built-in, universal, legacy custom, and user-defined section controls now use one consistent action style.
- Profile text fields can be resized vertically and remember their custom input height.

## Custom character summaries

- The summary below a character name can now use a built-in field, universal custom field, ordinary custom field, or a field from a custom section.
- Multi-value fields render as a readable joined summary.
- Empty, renamed, or removed sources safely fall back to the automatic personality → occupation → role summary.

## Reliable spreadsheet row heights

- Manual drag resizing and automatic row-height changes are captured immediately.
- Closing or switching tabs cannot replace a fresh resize with a lagging Univer workbook snapshot.
- On reopen, explicit dimensions stored in `datasheet.xlsx` take precedence over stale auxiliary metadata.
- Existing column-width persistence remains protected by the same close/save safeguards.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.3.zip`.
