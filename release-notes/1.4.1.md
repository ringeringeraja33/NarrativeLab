# NarrativeLab 1.4.1

Fixed persistent Windows file-lock failures when adding an open project to a series, removing it from a series, or creating a series from it.

## Reliable project moves

- NarrativeLab now freezes project-scoped background writes and drains pending tracker, System-data, workbook, Canvas, and project-manifest save queues before moving a project folder.
- Open NarrativeLab views and ordinary Obsidian Markdown, Base, and Canvas tabs inside the project are temporarily unloaded, then restored at the correct path after the move.
- If Windows still holds the directory handle, NarrativeLab automatically switches to a transactional file-by-file move through Obsidian.
- The project manifest moves last, preventing a partial destination from being discovered as a duplicate project.
- If any child file remains genuinely locked, every completed file move is reversed and the original project is restored.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.1.zip`.
