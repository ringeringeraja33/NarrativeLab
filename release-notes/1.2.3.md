# NarrativeLab 1.2.3

A Concept Grid, Narrative Canvas, and Library follow-up to 1.2.2.

## Additions

- Concept Grid now includes the open-source Univer sheet tools: filter, sort, find/replace, data validation, conditional formatting, notes, tables, comments, drawing, and hyperlinks. Freeze panes, merges, and extra sheet styles survive save and remount.
- The spreadsheet ribbon is ordered Home → Data → Insert → Formula.
- The Markdown cell editor title shows A1 coordinates first, then row and column labels when they exist.
- Narrative Canvas can open a Library profile overlay for characters, locations, and other entries, and keeps canvas entries in sync with Library files.
- In the node library, only the Entry type stays locked. Other types can be removed.

## Fixes

- Canvas no longer flashes the wrong theme on the first paint.
- Adding or deleting Concept Grid rows and columns now persists.
- Unused CSS and unused helper code were removed.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
