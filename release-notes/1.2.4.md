# NarrativeLab 1.2.4

A Concept Grid save-and-restore follow-up to 1.2.3.

## Fixes

- Cell edits are written into the document as they happen. A lagging Univer `workbook.save()` snapshot can no longer persist only the first half of a typing burst.
- Incomplete or empty spreadsheet snapshots cannot overwrite a richer `Library/datasheet.xlsx`.
- Restoring the last focused Concept Grid tab no longer paints a blank “Page 1” workbook before the real datasheet has loaded.
- Library Locations and Characters archives keep their scroll position when the list refreshes.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
