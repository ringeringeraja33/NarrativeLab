# NarrativeLab 1.3.8

Corrected vault-wide writing statistics while preserving every legacy record for recovery.

## Writing tracker

- Vault totals, daily averages, and heatmaps now use the combined `System/stats.json` ledgers from NarrativeLab projects as their authoritative source.
- Old global-only records that cannot be attributed to a project no longer inflate the displayed total.
- Excluded legacy records remain stored in `writing-tracker.json` and are summarized in the tracker panel instead of being deleted.
- Reconciliation stops if a project ledger cannot be read, preventing a partial scan from replacing the current vault ledger.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.3.8.zip`.
