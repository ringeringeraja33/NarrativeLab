# NarrativeLab 1.5.8

## 中文

- 资料表格在单元格编辑期间保持 Univer 原生编辑状态。自动保存不会强制提交、失焦、刷新或重新挂载正在输入的单元格，连续打字更流畅。
- 每次输入都会同步写入按库、按项目隔离的轻量恢复记录。即使刚输入完就关闭 Obsidian、Excel 文件写入尚未完成，重新打开后也会恢复文字并继续保存。
- 恢复记录只会应用到仍保持原始内容的单元格，不会覆盖后来从 Excel、Univer 或其他窗口写入的新内容。
- 完整文档同步会合并短时间内的连续输入，工作簿写入延后到输入停顿后执行，降低大型表格编辑时的主线程负担。
- 更新 TypeScript、ESLint、CodeMirror、Markdown-It 等开发依赖，并通过完整单元测试、启动测试和发布检查。

## English

- Keep Univer's native cell editor active during Concept Grid autosaves. Saving no longer commits, blurs, refreshes, or remounts the cell being edited, preserving uninterrupted typing.
- Mirror each active edit into a lightweight vault- and project-scoped recovery journal. Text entered immediately before Obsidian exits is restored on the next launch even if the workbook write did not finish.
- Apply recovery data only when the cell still matches the value on which the edit began, so stale recovery records cannot overwrite newer Excel, Univer, or multi-window changes.
- Coalesce full-document synchronization during typing and defer workbook writes until input pauses, reducing main-thread work on larger grids.
- Update TypeScript, ESLint, CodeMirror, Markdown-It, and related development dependencies with complete unit, startup, and release validation.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
