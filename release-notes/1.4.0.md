# NarrativeLab 1.4.0

Improved series project moves on Windows and made writing-tracker weekday headings compact and readable.

## Series project moves

- Adding an open project to a series, removing it from a series, or converting it into a series now flushes and temporarily unloads project-bound NarrativeLab tabs before renaming the folder.
- The same tabs are restored in place after the operation, with their saved project bindings updated when the folder moved successfully.
- Folder moves retry temporary Windows file locks from autosave, sync providers, antivirus, or external editors.
- Each retry checks the real source and destination state so a rename that completed on disk is not reported as a failure or repeated.

## Writing tracker

- English weekday headings in the sidebar and yearly heatmaps now display as `M T W T F S S`.
- Chinese weekday headings remain `一 二 三 四 五 六 日`.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation artifacts are `main.js`, `manifest.json`, `styles.css`, and `narrative-lab-1.4.0.zip`.
