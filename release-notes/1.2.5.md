# NarrativeLab 1.2.5

A Concept Grid isolation and edit-persistence follow-up to 1.2.4.

## Additions

- The overflow worksheet list (the sheet menu with 1稿 / 草案 / and other tabs) now has drag handles so worksheets can be reordered from that list.

## Fixes

- Deleting or editing the first row, first column, or A1 now saves. Univer’s explicit null / empty-cell clears are treated as committed, including leftover axis-cell Markdown.
- Closing a project while its Concept Grid tab is open no longer blanks other open projects’ spreadsheets. Each grid keeps its own workbook id, and surviving hosts relayout instead of inheriting a disposed instance.
- Fast edits can no longer drop other worksheets from a lagging `workbook.save()` snapshot. Opening a grid no longer flashes a blank “Page 1” workbook before the real datasheet loads.

## Compatibility

Requires Obsidian 1.12.7 or later. Installation is unchanged: `main.js`, `manifest.json`, and `styles.css`.
