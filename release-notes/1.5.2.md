# NarrativeLab 1.5.2

## 中文

- 优化导航器自动开启：布局恢复完成后挂载内容，合并重复打开请求，保留当前编辑焦点。
- 项目初始化期间立即显示加载提示，减少空白等待；已被元数据缓存索引且不含 frontmatter 的普通笔记不再重复从磁盘读取。
- 文件列表过滤、界面翻译和拼写检查仅处理新增 DOM 子树，并复用文件列表观察器，减少布局恢复期间的重复扫描。
- 合并导航器刷新请求，关闭视图后丢弃过期任务。
- 新增“显示启动诊断”命令，便于区分插件初始化、布局等待和项目加载耗时。各阶段可能重叠，请勿将耗时直接相加。
- 增加启动、布局恢复和项目发现回归测试。实际启动时间取决于仓库规模、磁盘和其他插件。

## English

- Mount Navigator content after layout restoration, coalesce repeated open requests, and preserve editor focus during automatic opening.
- Display a loading state while projects initialize and avoid redundant disk reads for cached notes without frontmatter.
- Process only newly inserted DOM subtrees for file filtering, localization, and spellcheck; reuse file-explorer observers.
- Coalesce Navigator refreshes and discard stale work after closing the view.
- Add the Show startup diagnostics command. Phase durations may overlap and must not be summed.
- Add regression coverage for startup, layout restoration, and project discovery. Actual startup time depends on vault size, storage, and other plugins.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the plugin directory with the release assets. Restart the application or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported application version: 1.12.7.
