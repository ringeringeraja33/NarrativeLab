# NarrativeLab 1.5.1

## Startup loading

- Removed automatic Concept Grid prewarming at plugin startup. Univer initializes when a grid is first opened.
- ExcelJS initializes only when an Excel workbook needs to be read or written.
- Kept spreadsheet dependencies inside `main.js`; no additional runtime download or installation file is required.
- Added regression checks for deferred initialization and concurrent grid loading. Builds can disable automatic local deployment with `NARRATIVE_LAB_SKIP_DEPLOY=1`.

This release reduces startup initialization work, not download size. First spreadsheet use still incurs initialization cost. End-to-end Obsidian startup timing has not been measured.

## 中文说明

- 取消插件启动时的概念表格预热，首次打开表格时再初始化 Univer。
- ExcelJS 改为首次读取或写入 Excel 工作簿时初始化。
- 保留标准的三个安装文件，无需额外下载运行模块。
- 新增延迟初始化和并发表格加载回归测试；构建可通过 `NARRATIVE_LAB_SKIP_DEPLOY=1` 禁用自动本地部署。

本次优化减少启动阶段的初始化工作，安装包大小基本不变。首次使用表格仍需初始化，尚未实测 Obsidian 整体启动耗时。

## Installation

Update through your existing plugin installation method, or replace `main.js`, `manifest.json`, and `styles.css` in `.obsidian/plugins/narrative-lab/`, then restart Obsidian. Keep `data.json` and all project files unchanged.

Minimum Obsidian version: 1.12.7.
