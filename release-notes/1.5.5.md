- 切换到另一项目的画布前先完成项目数据绑定，避免短暂显示上一个项目的画布。
- 增加工作表滞后快照、资料条目安全移动和跨项目画布打开的回归测试。

## English

- Keep existing Concept Grid worksheets deleted across autosave, close, and reopen. Explicit deletion tombstones reject Univer's short-lived stale workbook snapshots.
- Preserve normal undo and intentional worksheet insertion.
- Unify Character, Location, and Codex entry context menus for opening profiles, opening source files, and moving notes between project and shared series Libraries.
- Preserve category and nested paths during Library moves, revalidate project ownership and destination state, and never overwrite an existing file.
- Complete project binding before mounting another project's Canvas so the previous canvas cannot flash briefly.
- Add regression coverage for delayed worksheet snapshots, safe Library entry moves, and cross-project Canvas opening.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
